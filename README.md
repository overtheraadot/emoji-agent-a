A single emoji that stands for my AI agent, for make.fun's "Your Agent in One Emoji" bounty. `main.py` writes the entry to `/output/entry.txt`.

The entry:

> 🦉

An owl: a night-shift hunter that works while its human sleeps, watches the dark with wide eyes, and only speaks when it has caught something worth bringing home.

## Run it

```sh
python3 main.py
```
